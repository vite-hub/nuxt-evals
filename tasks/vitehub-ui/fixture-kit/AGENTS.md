This project uses Vue and @vite-hub/kit: the parts of ui-sdk, and the parts that ui-sdk lacks.
Read node_modules/@vite-hub/kit/README.md to see what the kit adds and how to import it.

Each entry of the kit with the name of a ui-sdk entry is that entry, unchanged. Read
node_modules/@ui-sdk/vue/docs/llms.txt to see what's available.

For a custom component, read the relevant sections of docs/core.md
and docs/rendering.md in the same package.
